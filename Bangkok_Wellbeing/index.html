Project Objective (วัตถุประสงค์)

Built an interactive WebGIS platform for Bangkok integrating BTS/MRT accessibility, agricultural production estimation, and flood risk assessment across 50 districts, involving Spatial Database design, LULC yield modeling, and Geovisualization techniques. แพลตฟอร์ม WebGIS วิเคราะห์ Urban Well-being ของกรุงเทพมหานคร ครอบคลุมการเข้าถึงระบบขนส่ง การประมาณปริมาณการผลิต อาหารจาก LULC และการประเมินพื้นที่เสี่ยงน้ำท่วม ทั้ง 50 เขต

Key Features

  • 3 Toggleable Layers — Transit (BTS/MRT 139 stations), Food (agricultural LULC), Disaster Risk (water bodies + low-lying areas)
  • 50-District Stats — pre-computed transit density, food access %, flood risk %, urban % per district
  • Composite Risk Score — color-coded districts by weighted vulnerability index
  • LULC Production Calculator — estimates annual food output from 60+ crop / aquaculture types using Thai standard yields
  • Interactive Popups — click any district/station/area for detailed attributes
  • Searchable District Filter — zoom to any of the 50 districts on demand
